# Тестовое Neowise. AI-помощник для входящих заявок

Ориентир — 45–60 минут. Менеджер вводит текст заявки, получает тему и черновик ответа. Он читает результат и сам решает, что отправить клиенту.

## Запуск

В репозитории есть сервер, HTML-страница и имитатор модели. Нужен Node.js 20 или новее. Зависимостей и ключей нет.

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно задать через переменную `PORT`.

## Проверка

```sh
node --test
```

## Что изменено

1. `POST /api/triage` — валидация тела (битый JSON, пустое/нестроковое поле `text`) → 400 `invalid_input`; ответ модели проверяется на объект, допустимую тему и непустой черновик; таймаут ожидания модели — 300 мс (`AbortSignal.timeout`). При таймауте, ошибке модели или неподходящем ответе → 200 `manual_review` с `topic: null`, `draft: null`.
2. Страница — отдельные поля для статуса, темы и черновика; при любом сбое предыдущий черновик очищается.
3. Исполнимый тест `test/triage.test.mjs` покрывает валидность ввода, битый JSON, пять сценариев сбоя (`[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]`) и корректный сценарий.

Для локальной проверки имитатор принимает любой обычный текст. Метки `[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]` включают отдельные сценарии сбоя.
